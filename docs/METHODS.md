# 实现边界与验收口径

主运行器保留原独立复现的RQ1/RQ2/RQ3/RQ5阶段；RQ4作为单独对比扩展。HoloClean/Adult/Hospital组合未纳入，不能把目录或命令存在当作已复现证据。

关键协议：数值/类别水印修改在同一深拷贝中累积；类别绿色域数量向下取整，零假设概率使用可实现的effective_gamma并同时记录nominal_gamma；原始与水印下游模型共享划分及随机种子；Housing保持complete-case缺失处理。插入/删除后的字段匹配与论文概述存在口径差异，细节保留在LEGACY_PROTOCOL.md。

数据来自显式指定目录。同优先级同名输入若哈希不同则拒绝仲裁，哈希相同才稳定选择。默认禁止网络下载；--allow-downloads是显式授权。演示生成器只写到新目录，不复制原始私有数据缓存。真正的原数据、密钥、论文附件和历史实验成绩不在本仓库。

resume核验配置指纹、阶段完成状态和全部产物哈希。跨平台文件锁防止同时写入同一结果目录。改动输入内容、计算参数或输出产物时会触发拒绝/重跑，而不是默默将不同运行混为一组。

静态审计只检查源码、文件依赖和历史输出，不执行任何代码；已有execution_count/旧输出保持UNVERIFIED。输出限制在源树之外的新文件，避免审计覆盖被审计工件。

发布验证覆盖小规模合成数据、核心测试、CPU对比以及可选XGBoost路径；没有运行真实数据的全量GPU实验。不存在新的SOTA声明，也不把合成fixture上的数值包装为论文成绩。
