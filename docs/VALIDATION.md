# 验证范围

本地使用Python3.12.13在独立虚拟环境执行测试，随后用隔离Python从无关临时目录运行安装后的CLI。CI覆盖Linux和Windows的声明最低Python版本及Python3.12。可选依赖单独在Linux运行。

水印平台测试覆盖数值/类别水印、effective_gamma、行匹配、输入哈希仲裁、恢复、成对模型种子、RQ4对比确定性、静态审计、进程锁与公开CLI。依赖参考：NumPy2.5.4、pandas2.3.3、scikit-learn1.9.1、filelock4.2.10；可选XGBoost3.4.1、scikit-image0.26.0。

本地实际执行了合成数据的检测/ROC及三方案CPU对比，其中XGBoost效用路径完成。某些位可出现undecidable诊断，未补写缺失证据。没有执行真实数据全量GPU实验；CUDA回退日志机制存在，不等同于已验证所有GPU组合。

隐私检查覆盖所有跟踪内容、可达Git历史与提交/标签元数据，人工检查确认个人标识、原目录路径、数据和私密状态未混入源码。原始资料完整性由单独私有快照的逐文件SHA-256与恢复验证负责；公开项目不是原始资料备份。
